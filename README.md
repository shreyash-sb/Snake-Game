# 🐍 Hungry Snake Game

A simple and responsive browser-based Snake game built with **HTML5 Canvas, CSS3, and Vanilla JavaScript**.

## ✨ Features

* 🎮 Smooth and responsive gameplay
* 🍎 +10 points for every apple
* 🏆 High score saved using `localStorage`
* 🌙 Dark & Light themes
* 🔊 Built-in Web Audio sound effects
* ⏸️ Pause / Resume
* 🔄 Quick Restart
* ⌨️ Keyboard controls
* 📱 Touch swipe and virtual D-Pad controls
* 📐 Responsive design
* 🚫 No external dependencies

## 🎮 Controls

| Key           | Action         |
| ------------- | -------------- |
| `W` / `↑`     | Move Up        |
| `A` / `←`     | Move Left      |
| `S` / `↓`     | Move Down      |
| `D` / `→`     | Move Right     |
| `Space` / `P` | Pause / Resume |
| `R`           | Restart        |
| `T`           | Toggle Theme   |
| `M`           | Toggle Sound   |

**Mobile:** Swipe on the game board or use the on-screen D-Pad.

## 🚀 How to Run

No installation or build step is required.

### Directly Open

Open `index.html` in any modern web browser.
